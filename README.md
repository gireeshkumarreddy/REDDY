# Gireesh portfolio

A responsive, orange-and-black portfolio with a portrait entrance, concise service specifications, and a prominent project-call section.

## Deploy on Vercel

Import this repository at https://vercel.com/new and deploy. The root `vercel.json` selects the static project output. No installation or build step is required.

## Contact and booking

Public settings are in `site-config.js`. The contact address is `gireeshuiux@gmail.com`.

Set `bookingUrl` to the public Google Calendar appointment-schedule URL to enable the booking button and, for full schedule URLs, an embedded booking page. Until it is configured, visitors request calls through email. This does not automatically reserve a meeting.

Add the owner’s LinkedIn and Instagram profile URLs to display the social links. Do not put passwords, access tokens, or private calendar data in this repository.

The homepage is `index.html`; styles, behavior, and the portrait are served directly from this repository. Motion respects reduced-motion preferences.
